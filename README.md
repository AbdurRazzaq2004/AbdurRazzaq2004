## How I Work

- **Everything as Code** — infrastructure, configuration, policies, and pipelines live in Git and are reviewed like code.
- **GitOps-first** — the desired state is declarative; controllers reconcile it continuously, with fast rollback by revert.
- **Security by Default** — secrets in a vault (never in Git), scanning and policy gates in CI, mTLS between services, least privilege.
- **Self-Hosted & Portable** — designed to lift-and-shift across cloud and on-prem, avoiding lock-in to managed services.
- **Observability-Driven** — metrics, logs, traces, and actionable alerts before scaling; measure, then optimize.
- **Automation over Toil** — repeatable playbooks and pipelines instead of manual steps; rollback-ready and documented.
